Tentang Saya

Frontend/Backend Dev &
Data Scientist

Saya SR Pakpahan, SST, seorang profesional di bidang teknologi informasi dengan latar belakang kuat sebagai lulusan Sekolah Tinggi Ilmu Statistik (STIS) Jakarta, jurusan Statistika Ekonomi. Berbekal pengalaman lebih dari 19 tahun sebagai PNS di Badan Pusat Statistik (BPS), saya mengembangkan ketelitian analitis yang kuat dalam pengolahan data dan manajemen proyek.

Kini saya berfokus pada pengembangan aplikasi web dan desktop modern menggunakan React, serta pemanfaatan Data Science. Dengan perpaduan kemampuan statistik, analisis data, dan rekayasa perangkat lunak, saya selalu berusaha memberikan solusi terbaik yang efisien, akurat, dan dapat diandalkan.
